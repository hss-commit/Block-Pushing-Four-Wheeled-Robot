# 实车与诊断测试

当前入口及完整盘点见 [程序与测试清单](../程序与测试清单.md)。日常双击根目录 **启动机器人.cmd**，依次进行只看识别（2）、短动作（3）、直接推块（1）；自动接近（4）留作进阶。

| 保留工程 | 用途 |
| --- | --- |
| [单电机试转](单电机试转/README.md) | 接线、通道与轮向诊断 |
| [手机热点联动测试](手机热点联动测试/README.md) | 当前推荐实车固件 |
| [视觉无线联动测试](视觉无线联动测试/README.md) | ESP32自建热点备用方式 |
| [视觉蓝牙联动测试](视觉蓝牙联动测试/README.md) | 蓝牙备用方式 |
| [无线最小诊断](无线最小诊断/README.md) | 不驱动电机，排查无线启动及供电 |

单块推送复用手机热点联动固件，不新增重复工程。按 [推块步骤](../control/单块自主推送测试说明.md) 设置尺寸、固定相机、选四个真实场地内角、点击唯一方块取色；稳定倒计时后自动前进，方块移动约10厘米后停止。初始须对准，不自动转向，尚需现场验收。

已移除早期ESP32串口冒烟和旧WiFi网页遥控源码及配置；历史通过记录仍保留。电脑端检查用根目录 **运行软件检查.cmd**，不连接真车，包含完整推块联调和故障停车。

新增菜单 **5：键盘遥控**，无须摄像头或尺寸；W/S/A/D及方向键控制前后左右。需先重新上传本目录的新版手机热点联动固件。见 [键盘遥控步骤](../control/键盘遥控测试说明.md)。

菜单 **6：多块入区测试** 是逐块送入黄色区、退开核验后自动换下一块，空格启动，X停车。须上传最新手机热点联动固件（80ms细动作），见 [多块入区步骤](../control/多块入区测试说明.md)。
