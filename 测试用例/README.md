# 测试用例

## 当前新增：手机热点联动测试

电脑和ESP32共同连接手机热点时，烧录 [手机热点联动测试](手机热点联动测试/README.md)，手机热点设置为 `Robot-Test` / `esp32car123`、2.4GHz，电脑根据ESP32串口打印的IP连接。先用浏览器查询 `/status`，再运行根目录 `启动手机热点联动测试.cmd`。这是一种替代联网方式，独立供电问题仍需另行核对，真实热点与实车动作待验证。

## 当前新增：视觉蓝牙联动测试

若改用蓝牙，烧录 [视觉蓝牙联动测试](视觉蓝牙联动测试/README.md) 工程；电脑配对 `ESP32-Vision-BT`（PIN `1234`），先运行根目录 `检查蓝牙连接.cmd`，再使用 `启动视觉蓝牙联动测试.cmd`。与Wi-Fi版共用视觉逻辑和电机接线，蓝牙尚待实车验证；独立供电问题另行核对。

## 01 ESP32 串口测试

目标：确认 ESP32 能连接电脑、成功上传程序并运行。通过后再接电机驱动板。

1. 暂时只用 USB 数据线连接 ESP32，不连接电机驱动板和电机。
2. 在 VS Code 中安装 PlatformIO IDE 扩展，使用“文件 → 打开文件夹”打开 `ESP32串口测试`。这是已按 ESP32-WROOM-32 配置好的 PlatformIO 工程。
3. 等待 PlatformIO 首次安装完成。在底部 PlatformIO 工具栏依次点“√”编译、“→”上传、“插头”打开串口监视器。首次编译还会下载 ESP32 工具包，可能较慢。上传时若提示选择串口，选设备管理器中显示的 COM 端口（此前为 COM3）。
4. 串口监视器每秒看到一次 `ESP32 OK` 即通过；波特率已在 `platformio.ini` 设为 `115200`。

板载电源灯亮只表示板子通电；此用例检查程序是否真正运行。

2026-10-09 实测：PlatformIO 编译及 COM3 烧录成功，串口监视器在 115200 波特率下连续显示 `ESP32 OK`。

## 02 单电机试转

电池、驱动板和一台电机接好后，打开 [`单电机试转`](单电机试转/README.md) 工程，按其接线与串口操作步骤低速试转。

## 03 Wi-Fi 遥控测试

四路电机架空后，打开 [`WiFi遥控测试`](WiFi遥控测试/README.md) 工程，让手机连接 ESP32 热点并通过网页发送 1 秒动作。

## 04 视觉无线联动测试

打开 [`视觉无线联动测试`](视觉无线联动测试/README.md) 给 ESP32 烧录独立测试固件。电脑连接其热点，手机 USB 提供摄像头画面，再运行根目录 `启动视觉无线联动测试.cmd`；识别稳定后按空格触发一次约 250 毫秒低速直行，R 准备下一次，X 停止。先架空验方向与停止。本测试不包含导航和推块策略。
