# 视觉 → Wi-Fi → ESP32 → 电机：单次短直行测试

**2026-10-27 后续更新：** 本固件已额外支持 `/step` 的120ms前进/原地左右转向，供根目录 `启动视觉自动接近测试.cmd` 使用；旧的 `/pulse` 250ms直行保持兼容。新模式需重新烧录本工程，详见 [自动接近测试说明](../../control/自动接近测试说明.md)。

用于先验证电脑识别画面后能自动发送动作请求。每次在电脑画面按空格授权，识别稳定后才能发送一次低速直行请求。动作沿用已有四路同向协议 `$Car:0.1,0.1,0.1,0.1!`，ESP32 约 250 毫秒后主动发送停止；不需要手机按方向按钮。它不是完整导航或推方块程序，不会自动驶向目标点。

## 1. 给 ESP32 烧录本目录

1. 先让四个车轮悬空，驱动板开关 OFF。沿用已验证接线：ESP32 D17 → 驱动板 UART RX，两板共地；UART RX 回读尚未接入。驱动板由原有电池供电，ESP32 暂用 USB 供电，勿把 12V 接到 ESP32。
2. VS Code「文件 → 打开文件夹」选择本目录 `视觉无线联动测试`，PlatformIO 先点 √ 编译，再点 → 上传（此前端口 COM3，按实际选择）。本工程会替换 ESP32 当前运行程序，旧测试源码保留。
3. 打开 115200 串口监视器，确认显示热点与地址。热点 **ESP32-Vision-Test**，密码 **esp32car123**，默认地址 **http://192.168.4.1**。

## 2. 连接画面和电脑 Wi-Fi

1. 手机经 USB 连接电脑，在 DroidCam 中确认画面，保持应用在前台。手机镜头要固定并完整看到四个轮胎。
2. **电脑连接 ESP32-Vision-Test 热点**，选择保留“无互联网”的连接。这里传指令的是电脑；手机是否连接热点不影响 USB 画面。
3. 打开驱动板，核对车轮确实悬空，避免电缆缠轮。

## 3. 运行电脑测试

双击项目根目录 **启动视觉无线联动测试.cmd**。它会先核对 ESP32 固件协议并发送停止请求，协议不匹配或连不上时退出。

- **N / P**：切换摄像头，切换前发送停止。
- 画面显示绿色车头箭头且稳定约 0.5 秒后，顶部显示 **READY**。
- **空格**：仅在 READY 时发送一次短直行请求；没有有效小车朝向时不发送。发出后不会自行重试运动请求。
- **X**：发送停止请求。
- **R**：准备下一次测试，重新稳定后再按空格。按住空格不会连续触发多轮。
- **S**：保存当前原始图、识别图与定位数据。
- **Esc / 关闭窗口**：发送停止后退出。

观察四轮方向是否符合实际车头方向。若出现侧移、转向或某轮反转，先停止，检查驱动板的 A/B/C/D 电机接线与电机方向；视觉箭头不参与本次电机通道映射。架空动作和停止可靠后，再选择空旷处验证一次短距离低速落地动作。先不要放方块，不做自主路线测试。

每次运行的事件日志和 S 保存图片在 `vision/results/wifi-pulse-时间/`。`pulse_queued` 只证明 ESP32 接受请求；串口 `PULSE` 只证明已向驱动板发指令；需要观察实车确认电机动作和停车，不等于已获得编码器反馈。

命令行可指定摄像头或 ESP32 地址：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\control\vision_wifi_test.py --camera 1 --host http://192.168.4.1
```

仅试识别与按键、不连接小车：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\control\vision_wifi_test.py --dry-run
```

## 停止行为与边界

电脑在识别丢失、朝向不确定、观测处理耗时超过 0.2 秒、车体位置/朝向突变、通信异常、按 X 或退出时发送停止，通信异常时结束程序。ESP32 电机计时任务独立于 HTTP，约 250 毫秒到期即发送停止，检查周期 10 毫秒，存在调度与实际机械制动延迟；电脑/画面/网络卡住不能延长这一轮动作。空闲时重复发送零速度。这里通过“有限时长单次动作”限制失联运行，不是已实现连续速度心跳协议。

识别沿用四个红黑轮胎，宽轮距为车头，默认须比另一对宽至少 8%。只能用于单辆已确认的小车，尚无多车身份跟踪、障碍检查、相机缓存延迟检测或物理距离标定。画面冻结可能无法仅凭图像判断；此次必须人工观察，短动作停止后再决定是否进行下一次。

网络接口：GET `/status` 核对 `vision-pulse-v1`；POST `/pulse`，表单 `id` 为 32 位十六进制唯一值；POST `/stop` 停止。设备忙时拒绝新动作，相同最后一次 id 重复请求不再次执行。根网页只有停止按钮，无网页前进按钮。
