# ESP32 Wi-Fi 遥控测试

本工程让 ESP32 自己发出 Wi-Fi 热点，手机连接后打开控制网页。使用现有 ESP32-WROOM-32 和四路电机驱动板，不需要路由器或手机 App。

1. 车轮悬空，沿用串口试转接线：ESP32 `D17` 接驱动板 UART `RX`，两板 `GND` 相连；驱动板 UART `5V` 和 `TX` 不接。驱动板仍由已确认的 12V 电池供电，ESP32 暂由电脑 USB 供电，切勿把 12V 直接接到 ESP32。
2. VS Code 用“文件 → 打开文件夹”打开本目录，使用 PlatformIO 的“→”上传程序。上传时驱动板开关先拨到 OFF，上传完成后再打开驱动板。
3. 打开串口监视器（115200），查看网页地址。手机连接热点 `ESP32-Car-Test`，密码 `esp32car123`；若手机提示“没有互联网”，保持连接。
4. 手机浏览器输入串口显示的地址（通常是 `http://192.168.4.1`），按网页按钮。每次前进、后退、左转、右转只运行 1 秒，随后自动发送停止命令；“立即停止”可随时发送停止命令。

左侧电机是 A/C，右侧是 B/D；左转时左侧停止、右侧前转，右转相反。先观察四个轮子的实际方向是否符合预期，再考虑落地运行。这个程序按时间发送速度命令，没有读取编码器或驱动板回执；网页和串口提示仅证明 ESP32 收到网页指令并发送了 UART 命令。
