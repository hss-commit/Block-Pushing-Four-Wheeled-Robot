# 电机试转与固定动作

适用：ESP32-WROOM-32 + 四路编码器电机驱动板 + 520 电机。

1. 驱动板开关拨到 OFF，ESP32 先拔掉 USB。将 ESP32 `D17` 接驱动板 **UART RX**，ESP32 `GND` 接驱动板 **UART GND**。驱动板 UART 的 `5V`、`TX` 暂不接。
2. 核对电机六线插头与驱动板插座的 `M-、5V、A、B、GND、M+` 线序；车轮悬空。电池仅接驱动板绿色端子的 `+`、`-`，不要接 ESP32。
3. VS Code 用“文件 → 打开文件夹”打开本目录。先给 ESP32 接 USB，用 PlatformIO 的“√”编译、“→”上传。上传期间驱动板保持 OFF。
4. 打开串口监视器（115200），再打开驱动板开关。发送 `1`、`2`、`3` 或 `4`，对应驱动板 A、B、C、D 单路，按 `0.1` 试转 1 秒后停止；发送 `5`，A+B 两路以 `0.5` 试转 2 秒；发送 `6`，四路同时以 `0.3` 试转 1 秒；发送 `7`，四路以 `0.3` 运行 1 秒，然后左侧 A/C 停、右侧 B/D 以 `0.3` 再运行 1 秒，最后四路停止；发送 `9`，只让右侧 B/D 以 `0.3` 转 1 秒，左侧 A/C 保持停止，用于单独测试左转。`0.5` 取自厂家示例，不代表电机全速。串口监视器发送行尾可任意设置。
5. 四台同时试转前，先固定电机并使车轮悬空、手和线远离转轴，确认电池及供电路径能承受四台电机同时工作。电机不转、持续转动、发热或异响时，立即拨回驱动板 OFF 并断开电池。

如果所有常规指令都失效，可发送 `8` 做 A 路短时诊断：只发送厂家示例的电机类型设置和 A 路 `0.1` 速度，1 秒后停止，不在启动前发送停止命令。若 A 路转动，说明驱动板至少执行了 UART 速度命令；若不转，仍无法只凭串口打印区分通信故障、供电问题和驱动输出问题。

`7` 按 A/C 左、B/D 右编写。它是按时间发送命令，未读取编码器；装车后需先确认四轮正向确实让车前进，左转也要先架空检查。此前四路试转出现“第一次能转、第二次不转”，原因尚未查明，先不要放地面运行此固定动作。

本程序只发送 UART 命令，没有接驱动板 TX，因此串口提示仅表示 ESP32 已发出命令，不能证明驱动板收到了命令或电机已经转动。
