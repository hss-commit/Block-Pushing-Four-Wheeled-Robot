## DroidCam 实时摄像头识别

1. 先在 DroidCam 电脑端连上手机，确认电脑端能看到画面，并保持运行。
2. 双击项目根目录的 `启动摄像头识别.cmd`。按 **N** 切换下一个摄像头，**P** 切换上一个，直到看到手机画面；没有画面时也可以切换。编号由 Windows 分配，不固定。
3. 固定手机，让场地四个内角都入镜。在预览窗口按 **Enter** 暂停选角；按左上、右上、右下、左下点选四角，再按 Enter 开始实时识别。
4. 点击画面中的方块中心取色，按原来的方法调节 HSV 和最小面积滑块。绿框、蓝黄分界线及半场归属随画面持续更新；默认显示紧凑编号，按 **D** 切换坐标标签。
5. **S** 保存当前原始帧、识别图、黑白图和坐标 JSON 到 `vision/results/`；**R** 返回实时预览并重新校正；**Esc** 或关闭窗口退出并释放摄像头。

手机位置、方向、镜头、缩放或场地位置改变后，按 R 重新选四角；分辨率改变或视频断流时程序停止，需检查连接后重启。坐标仍按 1200 × 1200 mm 平面场地估算，尚无畸变和高度补偿。识别结果没有接入电机控制。相连方块可能合并成一个区域。

可以指定初始摄像头编号，例如：

```powershell
.\.venv\Scripts\python.exe .\vision\photo_vision.py --camera 1
```

实时链路的自动校验使用合成视频和模拟按键，覆盖连续帧、取色、移动方块、保存、重新校正返回及断流；不能代替 DroidCam 硬件和窗口操作验收：

```powershell
.\.venv\Scripts\python.exe .\vision\test_camera_vision.py
```

## 照片识别（原有模式）

从项目目录双击 `启动视觉识别.cmd`，选择手机照片即可开始。当前版本是真正调用 OpenCV 的本地 Python 程序，照片不会上传。

1. 场地内侧四角都要入镜。用 JPG 或 PNG；HEIC 先转 JPG。本次演示目标区为黄色，蓝黄可以左右或上下排列。
2. 按 **左上 → 右上 → 右下 → 左下** 点击场地内角，按 Enter 确认。右键撤销上一个点，R 清空重选。
3. 程序根据蓝黄实际交界检测中线，紫色线为检测结果。点击校正后图中一个方块的中心取色。另一窗口显示黑白筛选结果；白色应该对应方块。
4. 调节 H（色相）、S（饱和度）、V（亮度）容差和 Min area（最小区域面积）。识别太少可适当增大容差，背景也变白时减小容差或重新取色。
5. 按 S 保存框选图、黑白图和坐标 JSON。每次保存生成 `vision/results/` 下的独立目录。Esc 或关闭窗口退出。

输出坐标单位为毫米，按 1200 × 1200 mm 场地换算，原点在画面左下，x 向右，y 向上。坐标系不代表胜负方向。窗口标注使用英文，以兼容 OpenCV 自带窗口。

## 反光漏检修复（2026-10-20）

取色改为点击位置周围 7×7 像素的中位数，处理红色色相跨界。分割改为先找较饱和的颜色种子，再扩展到相连的浅色、阴影区域；放宽区域必须包含至少三个种子像素，不再给亮度设置上限。H/S/V 滑块分别控制种子色相容差、饱和度下降容差、亮度下降容差；浅色扩展使用更宽的色相和饱和度范围。有效蓝黄场地边界存在时，仅接受两色场地凸包内的检测；边界无效时仍可能识别场外同色物体，此时不能给推送方向。

画面默认只显示编号、半场和短方向箭头，顶部显示计数。**D** 切换毫米坐标标签，完整坐标仍保存在 JSON。黑白图现在只显示通过面积和种子条件的区域。

## 中线、半场与黄色目标区（2026-10-20）

中线来自 HSV 蓝黄颜色区域的相邻边界采样与直线拟合，**不使用图片中心线代替检测**。程序检查两色覆盖面积、边界长度、拟合误差与颜色是否分居两侧；缺色、边界遮挡过大或拟合不一致时输出 `valid: false`，所有方块归属为 `unknown`，不画推送方向。

- `Y`（原标签 `Y:HOLD`）：检测区域在黄色侧，本次演示建议保留。
- `B`（原标签 `B:PUSH`）：检测区域在蓝色侧，短黄色箭头示意朝黄色侧。
- `LINE`（原标签 `LINE:PUSH`）：检测框碰到中线容差带，保守视为压线候选。一个框若包含多块，不代表每块都压线。
- `?`（原标签 `UNKNOWN`）：未检测到可靠中线，不给方向。

压线判定使用检测区域包围框及像素容差带，不是比赛计分裁定。箭头只是图片中的方向示意，未考虑机器人位置、障碍或推送深度，**不是可执行路径或电机指令**；尚未接入策略层。策略仍使用上下半场坐标，接入前需要统一场地朝向，不能把黄色直接当作 `lower`。倾斜原图中的像素法线也不能直接作为地面推送角度。

蓝色范围为 OpenCV HSV H=90～135、黄色 H=18～40，均要求 S≥80、V≥45。当前为固定光照阈值，换场地、光源或摄像头后须复测。当前只拟合一条直线，大范围遮挡、严重畸变或复杂同色背景可能导致失败或误判。
